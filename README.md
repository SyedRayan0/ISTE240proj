## Project Description
EventHub is a web-based subscription platform designed for event attendees to discover nearby events while enabling administrators and organizers to create and promote events through a centralized system.

## Folder Structure
- `backend/` — Spring Boot REST API with JPA and MariaDB
- `frontend/` — Standalone HTML/CSS/JS pages using Bootstrap 5
- `database/` — Database configuration and setup notes

## Technologies Used
- Java 17
- Spring Boot 3.5
- Spring Data JPA
- MariaDB
- Bootstrap 5
- Maven

## How to Run
1. Make sure MariaDB is running
2. Update `backend/src/main/resources/application.properties` with your DB password
3. Open the `backend` folder in IntelliJ
4. Run `Assignment1Application.java`
5. Open `http://localhost:8080` in your browser
# EventHub Web-Based Event Organizer Platform

EventHub is a web-based subscription platform designed for event attendees to discover nearby events while enabling administrators and organizers to create and promote events through a centralized system. The platform allows users to browse and subscribe to events, receive live notifications and updates, and stay informed about upcoming activities, while organizers and admins can manage events and monitor participation metrics through an interactive dashboard. **Team Members:** Syed Rayan Hashmi (ID: 764000072), Ali Faisal (ID: 415002117).
